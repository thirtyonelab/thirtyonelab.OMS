# Peraturan Wajib Agent

1. **Senarai Langkah Terlebih Dahulu**: Sebelum melakukan sebarang tindakan yang mengubah fail, mendeploy, atau melaksanakan sebarang skrip, Agent WAJIB memberikan satu senarai langkah-langkah ringkas namun terperinci kepada pengguna terlebih dahulu.
2. **Tunggu Pengesahan**: Agent dilarang keras untuk membuat sebarang perubahan (kecuali jika diarahkan sebaliknya) sehingga pengguna membaca dan mengesahkan rancangan tersebut.
